# Legacy Project Material

This directory preserves earlier CNC Toolbase systems and experiments so the active repository can remain understandable without losing history.

- `root-experiments/` contains the original small JSON workflow, training pairs, proposal scripts, and one-off import helpers.
- `v1-v2/` contains the earlier SQLite databases, Node viewer/database scripts, superseded project notes, and the preserved hosted page.

Nothing under `legacy/` is an active source of truth. Do not use these files for new database work unless deliberately reconstructing history or comparing a migration.
